# test_faces/

Face crops used to test any face-match / liveness step (e.g. comparing the
photo on the data page against a selfie), if vision_forensics.py ends up
doing face verification.

Do NOT commit real people's photos here without explicit consent.
Good sources for placeholder/synthetic faces:
  - https://thispersondoesnotexist.com  (AI-generated, no real identity)
  - Your own team members' photos, WITH their consent, clearly for testing only

Keep this folder small and add a note in the repo README about provenance
of every image in the dataset folder, real or synthetic.
